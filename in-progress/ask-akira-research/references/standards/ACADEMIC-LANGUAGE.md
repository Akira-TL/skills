# Academic Language and Terminology

本文件定义 `ask-akira-research` 的科研术语与学术表述纪律。目标不是把文字写得复杂，而是确保每一个术语都对应已有学术概念、可核验定义或用户明确批准的新概念，不让 Agent 为了叙事顺滑自行制造名词。

## 1. 优先使用已有学术术语

科研输出中的概念、过程、方法、统计量、生态学关系与证据层级，优先使用领域文献已经稳定使用的标准术语。不要为了“更像一个故事”改写成未经文献支持的近义词、缩写、组合词或看似专业的新标签。

当对某个中文译名、英文原词或近义表达是否属于标准学术用语存在不确定性时，先检查当前领域的同行评议文献、方法原始论文、权威数据库/学会术语或高质量综述中的实际用法。若没有稳定中文译名，宁可保留已经通行的英文术语或缩写，也不要自行直译出一个新中文名词。

相似表达不能仅凭语言感觉互换。例如 transmission、dispersal、acquisition、persistence、colonization、engraftment、source attribution、community assembly、ecological filtering 等词在不同研究设计中有不同证据要求；必须根据论文和领域惯例选择真正对应当前证据层级的术语。

## 2. 中文科研写作采用“中文标准术语（English term）”

用户使用中文时，面向用户和进入科研项目的人类可读科研文本默认使用规范中文学术表述。一个重要专业术语首次出现时，优先写成：

```text
中文标准术语（English standard term）
```

若领域通常同时使用缩写，可写成：

```text
扩增子序列变异（amplicon sequence variant, ASV）
宏基因组鸟枪法测序（shotgun metagenomic sequencing）
微生物来源追踪（microbial source tracking）
```

后续可使用已经建立的中文术语或标准缩写，不需要每次重复英文。若没有公认中文译名，直接使用领域通行英文术语，并在首次出现时用一句普通中文解释其含义；不要为了形式统一强造中文翻译。

中文科研项目的人类可读科学叙述必须以中文为主体。不得把章节标题、方法重建、证据评估、批判性审阅或结论边界整段改写成英文，也不要把本来有成熟中文学术表述的短语长期保留为英文叙述。论文原始英文题名、作者名、期刊名、数据库登记号、软件名、标准缩写和首次术语括注不受此限制。完成验证会机械识别明显的大段英文叙述，但这种检查只能发现粗粒度违规，不能替代主模型的术语自审。

## 3. 禁止自行造词、组合词和命名概念

Agent 不得自行把多个已有概念拼接成一个新术语，再把它当作学界已有概念使用。例如为了概括结果而创造一个“X–Y 轴”“某某效应”“某某屏障”“某某闭环”“某某生态模式”等命名，如果没有文献依据或用户批准，都不允许进入正式科研表述。

需要描述尚无固定名称的现象时，使用普通、可操作的描述性句子。例如与其给一个尚未命名的现象创造名词，不如明确写出“环境来源菌株在暴露后是否能够被检测、持续存在并建立稳定定殖”。描述事实不等于给事实命名。

内部工作流字段，例如 `Candidate`、`Active Uncertainty`、`Evidence Packet`，是本 Skill 的工程标签，不自动具有学术概念地位。面向用户的科研结论不得把这些内部标签包装成学界术语；必须回到领域已经存在的学术语言。

## 4. 新概念只能在与用户共同讨论后命名

研究过程中确实可能出现值得提出的新概念、操作性框架或新术语。Agent 可以指出“这里可能存在一个尚未有标准名称、值得共同定义的概念”，并解释：

- 现有术语为什么不足以描述它；
- 它与相邻已有概念有什么区别；
- 可操作定义是什么；
- 什么证据会支持或否定这个定义。

但在用户明确同意之前：

- 不给它固定名称；
- 不把暂定表达写入项目 canonical scientific prose；
- 不在后续分析中把它当作既定概念。

用户明确批准后，才可把批准的名称和操作性定义写入 `RESEARCH.md` 的 `Key Decisions`，并在后续项目中按该定义一致使用。Agent 不能把“用户没有反对”解释为同意。

## 5. 术语必须服从证据层级

即使一个词本身是标准学术术语，也必须确认当前数据是否达到使用它所要求的证据层级。特别避免：

- 检测到（detection）写成定殖（colonization）；
- 共现（co-occurrence）写成互作（interaction）；
- 来源归因（source attribution）写成传播（transmission）；
- 菌株相似（strain similarity）写成传播方向（transmission direction）；
- 统计关联（association）写成因果效应（causal effect）；
- 功能潜力（functional potential）写成功能活性（functional activity）；
- 预测功能写成实测功能；
- 相关机制写成已建立机制。

如果最准确的标准术语会让结论显得更弱，也必须使用准确术语。

## 6. 写作前的术语自审

在生成 `RESEARCH.md`、论文 sidecar、跨论文综合、derived report、论文/摘要/图注或面向用户的科研结论前，对关键术语执行一次自审：

1. 这个词是不是领域里真实存在的学术术语？
2. 当前中文译名是否是常用标准译法；如果不确定，是否已经核验？
3. 是否存在更标准、更精确的领域术语，而我只是为了语言变化用了近义词？
4. 这个术语暗含的证据层级是否高于当前数据？
5. 这是不是我自己拼出来的组合词或命名概念？
6. 如果确实是新概念，用户是否已经明确批准名称与定义？

任何一项不能确认时，回到原始文献或权威术语来源核验，或者改用不命名的描述性表述。
