# Rapid Vertical Slices

把工作拆成少量、可独立验证的纵向切片，而不是按数据库 / API / UI / 测试分层拆任务。

每个切片只记录：

- 它交付的可观察行为；
- 它被哪些前置切片真正阻塞；
- 它完成时使用什么证据验证。

优先形成 2～4 个切片；只有工作天然需要更多独立结果时才继续拆。没有 blocker 的切片可以立即进入执行或并行编排，不等待一次额外的用户“ticket breakdown 审批”。

如果拆分过程中出现产品、领域或不可逆架构决策，停止该分支并使用 Matt 的决策能力解决；不要把开放决策伪装成 implementation ticket。
