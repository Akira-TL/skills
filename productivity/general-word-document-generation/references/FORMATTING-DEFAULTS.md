# DOCX 默认版式与对象排版参考

本文件保存通用 Word 默认版式与对象级排版细则。只有在需要从空白文档建立默认视觉系统、或任务实际涉及对应对象时读取；用户提供的正式规范、模板与既有 DOCX 格式所有权始终优先。

## 默认页面设置

在用户没有提供其他规范时，采用以下通用正式文档设置。

| 项目 | 默认值 |
|---|---|
| 纸张 | A4，纵向 |
| 上边距 | 25 mm |
| 下边距 | 25 mm |
| 左边距 | 25 mm |
| 右边距 | 25 mm |
| 页眉距边界 | 15 mm |
| 页脚距边界 | 15 mm |
| 装订线 | 0 mm，除非用户明确要求装订 |
| 中文正文字体 | 宋体 |
| 西文正文字体 | Times New Roman |
| 正文字号 | 小四，12 pt |
| 正文颜色 | 黑色 |
| 正文对齐 | 两端对齐 |
| 正文缩进 | 首行缩进 2 个汉字 |
| 正文行距 | 1.5 倍行距 |
| 正文段前 | 0 pt |
| 正文段后 | 0 pt |
| 字符间距 | 标准 |

如果文档属于紧凑型课程论文、期刊稿件或用户明确要求单倍行距，则将正文行距调整为单倍；如果文档属于通知、函件或制度文件，可根据文种取消首行缩进并采用固定段落结构。不得在没有依据时随机改变页面尺寸、页边距和行距。

## 默认样式体系

### 通用正式文档样式

| 语义 | 默认格式 |
|---|---|
| 文档标题 | 黑体，二号或小二，18 pt，黑色，加粗，居中，段前 0，段后 18 pt，与下段同页 |
| 副标题 | 宋体或楷体，小三，15 pt，黑色，居中，段后 12 pt |
| 作者或单位信息 | 宋体，小四，12 pt，黑色，居中，段后 12 pt |
| 一级标题 | 黑体，三号，16 pt，黑色，左对齐，段前 18 pt，段后 8 pt，与下段同页 |
| 二级标题 | 黑体，四号，14 pt，黑色，左对齐，段前 14 pt，段后 6 pt，与下段同页 |
| 三级标题 | 黑体或楷体，小四，12 pt，黑色，左对齐，段前 10 pt，段后 4 pt，与下段同页 |
| 正文 | 中文宋体、西文 Times New Roman，小四，12 pt，黑色，两端对齐，首行缩进 2 字符，1.5 倍行距 |
| 摘要 | 中文楷体、西文 Times New Roman，五号，10.5 pt，黑色，两端对齐 |
| 关键词 | 中文楷体、西文 Times New Roman，五号，10.5 pt，黑色 |
| 图题 | 宋体或黑体，五号，10.5 pt，黑色，居中，图下方 |
| 表题 | 宋体或黑体，五号，10.5 pt，黑色，居中，表上方 |
| 图注、表注 | 宋体，小五，9 pt，黑色，左对齐 |
| 参考文献 | 中文宋体、西文 Times New Roman，五号，10.5 pt，黑色，悬挂缩进 |
| 页眉页脚 | 宋体，小五，9 pt，黑色，不使用彩色分隔线 |

字号允许根据文档篇幅和用户要求做整体调整，但必须保持稳定的层级关系。不得在同一级标题中随机混用字体、字号、颜色、缩进或段落间距。

### 标题编号

正式中文文档需要编号时，优先使用“一、”“（一）”“1．”“（1）”或阿拉伯数字多级编号。编号必须使用 Word 多级列表或程序化编号逻辑实现，不能把编号当作装饰符号，也不能使用“●”“◆”“▶”“✓”等图形充当章节编号。

标题层级必须连续。不得从一级标题直接跳到三级标题，不得出现只有一个子标题的孤立层级。标题末尾通常不加句号。

用户未要求编号且文档较短时，可以只使用无编号标题；但全文必须保持一致，不能一部分编号、一部分不编号。

## 标点、引号与中西文混排

中文叙述统一使用中文全角标点。双引号使用“”，嵌套引号使用‘’。禁止在中文正文中使用 ASCII 直引号 `"`、ASCII 单引号 `'`、方向不匹配的引号或中英文引号混排。

中文句子中的逗号、句号、冒号、分号、问号、感叹号和括号分别使用“，”“。”“：”“；”“？”“！”和“（）”。破折号使用“——”，省略号使用“……”。年份范围、页码范围和数值范围优先使用规范连接号，并在全文保持一致。

英文题名、拉丁学名、基因名、文件名、路径、网址、DOI、公式和代码按各自规则保留半角字符。不得进行会破坏 DOI、URL、版本号、文件路径、基因名称或数学表达式的全局全角化替换。

中文与英文、数字之间通常不额外插入空格；数值与物理单位之间保留一个半角空格，例如“10 mL”“37 ℃”“5 mg/kg”。百分号紧随数字，例如“12.5%”。

## 禁止 Markdown 视觉习惯进入 Word

### 禁止引用块样式

除非用户明确要求排版一段长引文，否则不得生成灰色底纹、左侧粗线、缩进卡片或网页式 blockquote。普通引用内容应直接融入正文，并使用中文引号和规范引文标记。

真正的长引文可以使用独立段落、左右适度缩进和略小字号，但保持黑字白底，不添加边框、阴影、图标和背景色。

### 禁止代码块误用

普通术语、路径、命令名、变量名和短代码不得自动放入灰色代码块。只有用户明确需要展示程序代码时，才使用等宽字体、浅灰或无底纹的代码样式，并控制分页和行宽。非技术文档不得出现代码块风格。

### 禁止网页式强调

不得把每个关键词都加粗，不得使用荧光高亮、彩色标签、胶囊标签、信息卡片、提示框、警告框和 FAQ 折叠块。加粗只用于标题、表头、少量真正需要强调的术语或结论。

### 禁止 Markdown 表格直译

不得把 Markdown 管道表格直接转换成宽度失控、边框繁杂、彩色表头的 Word 表格。必须重新判断表格是否必要、列数是否合理、文字是否适合表格，以及页面宽度是否容纳。

当内容更适合段落时，应改写为段落；当内容适合比较时，才建立 Word 原生表格。

## 表格生成规范

表格默认采用简洁、正式、无彩色装饰的 Word 表格样式，仅使用黑色、白色及必要灰阶。表格单元格中作为图片对象嵌入的照片、图表或数据可视化可以保留具有信息意义的颜色；表格文字、表头、单元格背景、边框、Word 形状和非图片色块图例不得自动着色。不得默认使用彩色表头、交替彩色行、彩色图例块、渐变、阴影、圆角卡片或粗重外框。

学术论文中的数据表优先使用三线表：仅保留表顶线、表头下分隔线和表底线，线条为黑色，正文不使用竖线。报告、方案、制度和信息汇总表可以使用简洁网格表：黑色或深灰细线，白色背景，无彩色填充。

表题放在表格上方，图题放在图片下方。表题与表格、图片与图题必须保持同页。表头加粗并根据内容选择居中或左对齐；数值列按小数点或位数对齐；同一列的小数位数保持一致。

表格宽度不得超出正文版心。优先设置固定列宽或按内容合理分配列宽，不依赖“自动调整到窗口”造成跨设备漂移。长表跨页时重复表头，不允许将一个短表无故拆到两页。单元格内不使用多余空行，不使用回车模拟行高。

表格中文字默认为黑色，中文宋体、西文 Times New Roman，字号通常为五号或小五。表格不应为了视觉丰富而改变字体颜色。需要强调合计行时，可使用加粗或双底线，不使用彩色底纹。

## 图片、图形与题注

图片必须保持原始宽高比，禁止拉伸变形。图片默认水平居中，宽度不得超出正文版心。图片分辨率应满足打印和屏幕查看需要，不能出现明显模糊、裁切或遮挡。彩色图片默认保留原始色彩，不执行自动灰度化、去饱和、主题色映射或统一着色。

图题使用“图 1　标题”或用户指定格式，位于图片下方，黑色、居中、无彩色标签。表题使用“表 1　标题”，位于表格上方。题注应使用统一的 Word 题注样式，并与正文中的交叉引用保持一致。

除非用户明确要求信息图或品牌视觉，不得自动绘制装饰性流程图、无意义图标、复杂箭头网络、渐变模块和卡片式结构。流程图、示意图或数据图作为图片插入时可以保留必要色彩；使用 Word 原生形状、文本框、SmartArt 或图表构建时属于非图片内容，默认只使用黑色、白色及必要灰阶。不得以“好看”为由随机配色，并应保证打印可读性。

## 分页、分节与版面稳定性

不得使用连续回车、连续空格、Tab 堆叠或大量空白段落控制页面位置。应使用段落间距、制表位、分页符、分节符、表格布局和样式实现稳定版式。

标题必须设置“与下段同页”，避免标题悬在页末。图题和表题必须与对应对象保持同页。正文应开启孤行控制，避免一页顶部或底部只出现一行正文。不得在页面末尾留下无意义的大面积空白，除非章节必须另起一页。

需要横向页面展示宽表时，应使用独立分节符，仅将对应页面设为横向，并在后续恢复纵向。页眉、页脚和页码必须在分节后保持连续或按用户要求重新编号。

章节另起一页时必须插入分页符，不得用多个回车“顶到下一页”。封面、目录、正文和附录需要不同页码规则时，应使用分节符和 Word 页码域实现。

## 页眉、页脚、目录与域

用户未要求时，不自动添加复杂页眉。需要页眉时，使用简短的文档标题、章节名或单位名，字体小五、黑色，不使用彩色横线和图标。

页码默认位于页脚居中或右侧，使用 Word 页码域，而不是手工输入数字。目录必须基于标题样式和 TOC 域生成，不能手工敲点线和页码。图表目录、交叉引用和编号同样应优先使用 Word 域或稳定的程序化字段。

超链接在默认正式文档中显示为黑色并保留下划线或采用与正文一致的视觉样式，避免 Word 默认蓝色和访问后紫色造成非图片内容出现彩色。用户要求保留标准超链接视觉时除外。
