# 学术 DOCX 字符与引用排版参考

本文件只规定学术/科研内容进入 DOCX 后的字符级格式和引用表示。文献来源准入、科学论证、Results / Discussion 语义、因果判断与结论强度仍由上游科研流程或用户的 canonical content 决定。

## 学术与科研文本的字符级格式

### 微生物及分类学名称

凡属级、种级及属种组合的拉丁分类学名称，必须使用真实斜体格式。属名首字母大写，种加词小写，例如 *Ruminococcus albus*。属名单独出现时仍斜体，例如 *Ruminococcus*。后文在无歧义时可写为 *R. albus*。

科、目、纲、门等高于属级的分类单元通常使用正体。菌株编号、血清型、保藏号和培养物编号使用正体，例如 *Escherichia coli* O157:H7 中，仅属名和种名斜体。未定种写作 *Bacillus* sp. 或 *Bacillus* spp.，其中属名斜体，sp. 和 spp. 正体。

OTU、ASV、MAG 编号、数据库占位名称、样本编号和基因组簇编号不得机械斜体。学名斜体规则必须应用于标题、摘要、关键词、正文、图题、图注、表题、表注和参考文献题名。

在 DOCX 中必须设置字符的 `italic` 属性，不能保留 Markdown 星号作为可见字符。

### 统计学符号

统计学变量和统计量中的单个拉丁字母按规范使用斜体。显著性概率写作 *P* < 0.05 或 *P* = 0.032，其中 *P* 必须大写并斜体。常见统计符号 *n*、*t*、*F*、*r*、*R*²中的字母使用斜体，平方数字使用上标。

SD、SE、CI、df、ANOVA、SEM 等多字母统计缩写通常使用正体。希腊字母通常保持正体，除非目标规范另有要求。不得把普通单词、化学符号、基因名称或分组名称中的字母 P 批量设为斜体。

比较符号两侧保留半角空格，数字小于 1 时保留前导零。表格中的显著性字母应使用真实上标格式，并在表注中说明比较范围和显著性阈值。

### 上标、下标与公式

化学式、数学式、单位指数、基因型和统计表达式必须使用真实上标、下标或 Word 公式对象，不得用普通字符位置模拟。复杂公式优先使用 OMML 公式；简单的平方、立方和化学下标可以采用字符级上标、下标。

## 参考文献与引用

引用格式必须服从用户、学校、期刊或项目规范。用户未指定时，应先根据文档类型选择常见的顺序编码制或作者—年份制，并全文保持一致。

不得自动把引文显示成网页式引用卡片、灰色引用块或聊天系统的 citation token。文中引用应作为普通正文的一部分，采用上标、方括号或作者—年份格式。参考文献表使用悬挂缩进和统一字号。

不得虚构作者、题名、期刊、年份、卷期页码、DOI 或访问日期。文献来源准入、数据库选择和检索策略不由本 DOCX Skill 决定：Akira Research 项目服从 `literature` / `research-standards` 的来源与证据规则，其他项目服从用户、机构、期刊或项目自己的规范。网页可以用于定位正式来源；普通网页、博客、自媒体和搜索结果页只有在目标文种或规范明确允许时才作为正式参考来源。
