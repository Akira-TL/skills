# 科研写作逻辑表达

本文件约束科研论文中的段落衔接、逻辑连接词和结论强度表达。目标不是让 prose 看起来“更像论文”，而是让已有逻辑关系被准确、稳定地表达。所有术语选择和中英文首次出现规则继续遵守 [`ACADEMIC-LANGUAGE.md`](../../akira-research/references/standards/ACADEMIC-LANGUAGE.md)。

## 1. 先判断逻辑关系，再选连接词

任何连接词都不能替代真实推理。写句间或段间衔接前，先判断当前关系究竟是：

- 补充 / 递进；
- 具体化；
- 转折；
- 对照；
- 原因；
- 结果；
- 解释 / 重述；
- 举例；
- 让步；
- 综合；
- 证据支持强度；
- 结论边界。

若说不清是哪一种关系，不要靠 `moreover`、`however`、`therefore` 等词强行制造逻辑。

## 2. 常用英文逻辑表达表

### 2.1 补充 / 递进

可优先使用：

```text
moreover
furthermore
in addition
additionally
```

用于在已有论点基础上补充同方向证据或进一步信息。若后句只是换一种说法，不要误用递进表达。

### 2.2 具体化 / 强调某一部分

```text
particularly
specifically
in particular
```

用于从较宽命题收窄到具体对象、条件或结果。

### 2.3 转折

```text
however
nevertheless
nonetheless
```

前后必须存在真实预期冲突、限制或转向。不要因为段落需要“显得有层次”就机械插入 `however`。

### 2.4 对照

```text
in contrast
by contrast
whereas
while
```

用于两个对象、条件、结果或解释的真实对照。`while` 容易同时承担时间和对照含义；若可能造成歧义，优先使用更明确的表达。

### 2.5 原因

```text
because
because of
due to
owing to
be attributable to
be ascribed to
```

原因表达隐含因果关系，只有 evidence boundary 允许因果解释时才能使用。若只是观察到相关关系，应改写为 association 或 compatibility，而不是使用因果连接词。

### 2.6 结果 / 推论

```text
therefore
thus
consequently
as a result
accordingly
result in
```

这些表达表示前文足以推出后文。尤其 `therefore` / `thus` 不得用来掩盖跳跃推断。若只能说结果与某解释一致，使用 `is consistent with` 等更弱表达。

### 2.7 解释 / 重述

```text
in other words
that is
namely
```

用于把同一命题换成更清楚的表述，不应偷偷增加新的科学内容。

### 2.8 举例

```text
for example
for instance
such as
```

举例只证明“存在这样的例子”，不能用单个例子替代总体证据。

### 2.9 让步

```text
although
even though
despite
despite the fact that
```

用于承认一个事实仍不改变后文主要判断。让步句中的事实同样需要证据支持。

### 2.10 综合多个结果

```text
taken together
collectively
overall
```

只有在前文结果能够共同支持一个综合判断时使用。`taken together` 不是把若干弱证据自动升级成强结论的工具。

## 3. 科研结论强度表达

科研写作中优先根据 evidence-to-claim fit 选择表达，而不是为了语气好看换同义词。

| 表达 | 通常表示 | 不应被理解为 |
| --- | --- | --- |
| `is consistent with` | 当前结果与某解释相容 | 已证明该解释 |
| `suggests` | 结果支持一个较弱推断 | 已经建立因果或机制 |
| `supports` | 证据对目标 Claim 提供实质支持 | 排除了所有替代解释 |
| `is associated with` | 存在关联 | 导致、引起 |
| `may` / `might` | 可能解释或可能效应 | 已被数据直接建立 |
| `cannot exclude` | 当前证据不能排除某可能性 | 该可能性已经得到支持 |
| `does not establish` | 明确指出证据不足以建立更强 Claim | 当前结果没有任何价值 |
| `should be interpreted in the context of` | 提醒读者适用边界或限制 | 用限制语模糊核心结论 |

如果现有证据已经建立明确效应，不要因为过度谨慎把所有结论都写成 `may`；如果证据只到 association，也不能靠 `suggests` 模糊地暗示 causality。

## 4. 常见逻辑误用

### `consistent with` ≠ `proves`

“与某机制一致”只说明数据没有反驳该机制；若存在其他同样可解释数据的机制，不能升级为“证明机制”。

### `associated with` ≠ `leads to`

关联不能自动推出方向和因果关系。

### `therefore` 需要真实推论

只有前文事实和推理足以支持后句时使用。若中间还缺一个关键假设，应补出假设或降低结论强度。

### `however` 需要真实转折

若后句只是新信息，不要为了段落变化机械使用转折词。

### 举例不能替代总体证据

单个地区、单个实验或单篇论文只能支持其对应范围，不能通过 `for example` 后直接推广到总体。

## 5. 专业术语保持一致，不为避免重复而随意换词

科研概念的稳定性高于词汇多样性。对 treatment、outcome、endpoint、sample、participant、subject、cohort、effect、association 等专业词，不得仅为了避免重复就使用近义词替换。

当需要检查普通修辞词、固定搭配或语域时，可以使用 dictionary、thesaurus 或学术语料进行核验；它们是**用法核验工具**，不是自动 synonym replacement 工具。候选词必须确认：

- 词义是否完全匹配；
- 是否改变专业概念；
- 是否符合学术语域；
- 常见搭配是否正确；
- 是否会改变 Claim 强度。

## 6. 中文科研写作同样按逻辑关系选择衔接

中文不需要为了“论文腔”机械加入“此外”“然而”“因此”“值得注意的是”。只有真实存在对应逻辑关系时使用。

常见对应关系可以采用：

| 逻辑关系 | 常用中文表达 |
| --- | --- |
| 补充 / 递进 | 此外、进一步、同时 |
| 转折 | 然而、但、尽管如此 |
| 对照 | 相比之下、与此不同、而 |
| 原因 | 因为、由于、可能源于 |
| 结果 / 推论 | 因此、由此、从而 |
| 解释 | 即、换言之、具体而言 |
| 举例 | 例如、比如 |
| 让步 | 尽管、虽然 |
| 综合 | 综合上述结果、总体而言 |

中文中的“因此”“从而”“导致”“证明”等同样受 evidence boundary 约束。

## 7. 反向提纲与段落单一信息

当一节文字“每句话都没错，但读起来仍然散”时，优先做反向提纲（reverse outlining），不要先继续加连接词。

对当前 section：

1. 写下这一节唯一的 section thesis / 核心任务；
2. 只抄出每个段落的 topic sentence；
3. 为每段写一句“它提供的 evidence / explanation 是什么”；
4. 检查 `evidence → paragraph message → section thesis` 是否连续成立；
5. 任何无法清楚映射到 section thesis 的段落，移动、拆分、降到 Supplement / 其他 section，或删除重复内容。

一个段落默认只承担一个主要信息或推理任务。若同一段同时在定义概念、报告结果、提出机制、讨论 limitation，通常应拆开。关键定义应在术语被反复使用之前出现；不要要求读者依赖后文才能理解前文名词。

反向提纲完成后再决定哪里真的需要 `however`、`therefore`、`for example` 等显式连接。若交换两个段落的位置几乎不影响逻辑，应重新检查它们是否只是并列堆积，而没有形成推进关系。

## 8. 段落衔接自审

完成一段或一节后，不只检查语法，而要检查：

1. 当前段的中心句是什么；
2. 每一句对中心句承担什么作用；
3. 相邻句之间是什么逻辑关系；
4. 使用的连接词是否准确表达该关系；
5. 是否存在可以删除而不影响逻辑的模板化过渡句；
6. 是否因为追求流畅而升级了 causality、mechanism 或 effect strength；
7. 下一段为什么应当跟在这里。

如果需要大量连接词才能让两个段落看起来相关，应先检查内容顺序和推理本身，而不是继续增加过渡表达。
