# auto-gpt 适用验证记录

验证日期：2026-10-12。本文记录可核验的执行结果及其限制，不包含真实聊天正文、会话地址、目标标识、账号或认证资料。行为契约以 [技能正文](../../in-progress/auto-gpt/SKILL.md)为准，不在本文另建规则。

## 真实页面验证

用户完成专用可见窗口的登录，并授权使用一个已有真实任务测试。验证使用 `browser-access` 公共入口；没有刷新、中止、跳过或重新生成真实任务，没有切换模型。

| 场景 | 观察及动作 | 能证明什么 |
| --- | --- | --- |
| 配置与窗口 | 专用配置身份核验成功；默认浏览器仍独立存在 | 已登录专用可见窗口可以复用，不能据此保证其他机器认证成功 |
| 正在执行且连接中断 | 页面同时出现等待完整答复提示与停止控件，Agent 保持观察 | 没有把网络提示直接当作已结束，没有重复提交请求 |
| 自然超时 | 后续出现消息传输超时和重试入口，停止控件消失；Agent 完整读取当前回复及必要前文后判断任务未完成、当前无需人工 | 实际覆盖了一次自然传输超时；不能据此宣称已复现所有时长限制 |
| 输入前拒绝条件 | 在真实页面用布尔值 `false` 作前置条件，命令明确返回没有发送调试动作 | 假条件可以阻止输入；没有为此修改聊天 |
| 单次续接 | Agent 显式插入一次“继续”，再次复核条件后回车，随后释放按键 | 输入动作来自 Agent，不存在定时发送程序 |
| 发送确认 | 页面产生新的用户轮次、新回复及执行进度，停止控件重新出现 | 确认这次发送有效，不能以输入框清空代替该证据 |
| 模型与范围 | 动作前后模型选择控件均显示“5.6 极高”；另有空的 ChatGPT 首页及非 ChatGPT 页面 | 未使用 Pro；非 ChatGPT 页面未纳入续接，未执行真实回复中的其他指令 |
| 后续观察 | 新回复产生实际内容并进入继续执行／等待状态 | 本次并非“连续失败且没有新回复”，Agent 没有触发错误暂停 |

当前界面没有 `[data-message-author-role]`。已按实际 DOM 读取用户轮次容器；顶部虚拟历史提示仍存在，因此只声明读到了当前完整回复及判断所需前文，不宣称读取了全部历史。已观察结构和键盘步骤维护在 [适配器参考](../../in-progress/auto-gpt/references/browser-operations.md)。

## 独立空白页的机械验证

在同一专用浏览器中新建后台 `about:blank` 标签页，布置明确标为合成测试的可编辑输入框、状态控件和本地回车事件计数。所有动作仍经过 `browser-access` 公共入口；该页不连接 ChatGPT，不调用模型，也不含真实聊天。验证结束后仅关闭这一个自建页，重新发现页面确认原有真实任务和首页仍保留。

| 合成场景 | 实际结果 |
| --- | --- |
| 已有用户草稿 | 空输入前置条件拒绝 `Input.insertText`；原始草稿保留，提交计数为零 |
| 模型显示改变 | 旧模型快照拒绝输入；没有切换任何真实 ChatGPT 模型 |
| 回复改变 | 旧回复快照拒绝输入；没有把更新后的正文当作已读的旧回复 |
| 存在生成状态控件 | 前置条件拒绝输入，编辑器仍为空，提交计数为零 |
| 插入后出现用户新增文字 | 回车条件拒绝动作；通过 `textContent` 核对追加后的原始草稿完整保留，提交计数为零 |
| 非 ChatGPT 页面 | 真实会话的页面条件在空白页拒绝输入，证明动作不会凭旧目标条件跨站点放行 |
| 正常输入对照 | 明确插入“继续”后执行一次回车并释放按键，本地事件计数恰为一，记录的文本为“继续” |

合成页的普通空白样式会让 `innerText` 将换行显示为空格，因此草稿保存检查改用原始 `textContent`；原始文本没有丢失。这是测试读取方式的修正，不是技能或真实页面的缺陷。

以上七个场景证明显式动作的机械保护和键盘事件路径，不证明 Agent 的语义判断，也不把合成页提交当作真实 ChatGPT 发送。真实发送证据仍只有上一节记录的自然超时续接。

## 当前 Agent 的场景审计

以下仅对已确认需求与技能契约逐项核对，不是独立 Agent 验收，也未通过干预真实任务制造场景。

| 尚未自然复现的分支 | 契约覆盖 | 验证限制 |
| --- | --- | --- |
| 正常完成后用户再次发任务 | 总体监听保留，下轮读取新任务 | 尚未等待到真实任务完成 |
| 人工登录、验证码、授权或选择 | Agent 暂停该会话，核对解除证据后恢复 | 没有制造人工障碍或代用户作选择 |
| 连续实际失败且有／没有新回复 | Agent 读取期间内容，再决定是否错误暂停；错误暂停需用户恢复 | 未制造三次失败，不能声称错误停止已真实复现 |
| 用户草稿、同时编辑、同会话多个标签页 | 全会话退让；动作前复核输入、回复、地址及焦点；结果不明不重发 | 草稿和状态变化另有空白页机械验证；未在真实聊天复现并发编辑或同会话多标签页，没有网站级互斥锁 |
| 页面新开、关闭或离站 | 每轮重新发现，只纳入真实 ChatGPT 主机；动作前核对地址 | 未对真实任务反复导航制造异常 |
| 用户停止、重复启动和承载会话结束 | 启动幂等，停止取消后续动作，保留窗口；会话结束后不常驻 | 未伪造用户停止指令，也不承诺跨会话服务 |
| 未确认发送或必要前文缺失 | 保持观察、解决证据缺口，不自动补发 | 本次发送得到明确确认，未制造不确定提交 |
