# communication

`communication` 把已经稳定的 scientific state 转成论文、报告、摘要、图表、补充材料、答辩或 reviewer response。

传播产物必须基于一个明确的 pre-communication source commit，并从 canonical Research / Design / Study / Data / Analysis / Interpretation 取事实。Title、Abstract、Discussion、Conclusion 和 Figure legend 都不能为了叙事冲击力升级 evidence boundary。传播文件是派生输出，不成为新的科研事实源。

对于 manuscript、thesis 和长篇 research report，默认先完整盘点写作材料，再采用“主要结论 → Results → Discussion → 反推 Introduction → Methods → Abstract / Title → Supplement / Appendix”的起草顺序，而不是从前言一路顺写。写 Results prose 前先用小标题、Figure / Table、关键 Observation、本节最窄结论和下一步关系搭出骨架；Introduction 中提出的主要问题、研究不足和 contribution 必须在后续 Results / Discussion 中形成闭环。

写作材料要求尽可能完整：主要结果、负结果、非显著结果、探索性结果、敏感性分析、QC、deviation、替代解释、局限、支持与冲突文献等都应先进入材料盘点，再决定进入 Main text、Supplement、Appendix 或只保留为 canonical support。正文可以聚焦，但不能因为结果不利于预期故事就让材料无记录地消失。

Results / Discussion 同时检查结构清晰、主次分明、图表结合、文献对比、深入分析和紧扣核心。机制和更一般规律需要主动讨论，但 Claim 强度仍由现有 evidence 决定；“与机制一致”不能写成“证明机制”。最终还要分别执行全文大逻辑和段落小逻辑审查，检查 Results 是否层层递进、前后章节是否首尾呼应、段落间是否存在真实逻辑关系。

`communication` 还维护受控的科研写作逻辑表达参考，覆盖递进、转折、对照、因果、解释、举例、让步、综合和结论强度。连接词用于表达已经存在的推理关系，不替代推理本身；专业术语保持一致，不为了避免重复而随意使用同义词替换。dictionary / thesaurus 可以用于核验普通词汇和固定搭配，但不能自动改写专业概念或升级科学结论。
